# ShopKit – React Homepage

- **Project:** ShopKit Homepage
- **Frontend:** React with Vite
- **UI Library:** React Bootstrap
- **Installation:** `npm install react-bootstrap bootstrap`
- **Components Used:** Navbar, Container, Button, Row, Col and Card.
- **Features:** Responsive Navbar, Hero section, three feature cards and Footer.
- **Benefit:** React Bootstrap saved time by providing ready-made UI components instead of writing them from scratch.
- **Run Project:** `npm run dev`
